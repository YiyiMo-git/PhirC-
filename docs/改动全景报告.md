## 1. 打歌核心：把"看得清、练得准"做到极限

### 判定系统

- **判定窗口三档分别可调**（Perfect / Good / Bad 各自独立），另有 **late 侧独立补偿**（默认 0 = 完全对称）——官方版只有一个总偏移
- **判定文字全面自定义**：PERFECT / GOOD / BAD / MISS 四种出现动画、字号可调、配色带同色外发光
- **漏键标记**：Bad / Miss 的位置在判定线上留一个淡出的叉，哪里断了连击一目了然
- **判定范围可视化**（judgement_range 模块，官方版没有）

### 视觉表现

- **音符拖影**：每个音符最多 255 个残影；判定线残影、判定线发光
- **音乐可视化**：判定线上按频谱跳动的声浪条——自写 FFT 实现，零额外依赖
- **触点标记**：圆形 / 方框等样式、颜色、透明度全部可调
- **打歌字体二选一**：「原版 Phigros 字体」↔「Phi-Recorder 字体」即时切换
- **三棱锥着色器背景**（trigrid vertex/fragment shader，自研）

### 第 9 章「噪域 / 红区」完整还原

按官方谱面 `blockAreaList` 逐项实现（block.rs + blockarea + rpe_next_block）：

- 区内触摸被拦截——压住的音符自然 Miss
- 入区瞬间音乐压成**低通滤波**水下感
- 官方贴图、触摸悬停反馈、溶解边界动画的完整表现

### 实时数据（九宫格、可自由定位）

- ACC、判定计数、最大连击、时间误差、预估 RKS、进度、FPS
- **Early / Late 实时提示**——直观看出自己偏快还是偏慢
- **暂停界面直接调判定偏移与音乐 / 音效音量**，不用退出重进

### 官方版没有的玩法级功能

- **时间倒流**：暂停菜单第 4 键，每 0.5s 快照、可回溯 6.5s（Judge::snapshot/restore）
- **练习模式**：变速（practice_speed）+ 自定义可视范围（practice_view）
- **全屏判定 + 黄键 / 红键保护**，防误触断连击
- **摇一摇重新开始**

## 3. 制谱器：内置一颗完整的 Re:PhiEdit

这是与官方版差距最大的板块——官方版**完全没有制谱功能**。

### 内置制谱器（ChartEditor.html + editor.rs）

- **三种格式通吃**：官方 Phigros JSON、PEC 文本、RPE JSON 读写往返
- **真实下落预览**：速度事件按秒积分（floorPosition），音符沿判定线局部坐标下落——公式与游戏引擎逐条对齐，**预览所见即游戏所玩**
- 事件插值接 30 种缓动函数；Hold 尾巴、假音符（fake）、音符 size 全支持
- **点哪放哪**：点击画布即放置音符（由离线距离反演拍位），拖拽同套反演
- **快捷键全对齐 RPEN**：Q/W/E/R 放置、Space 播放、Ctrl+Z/Y 无限撤销重做、Ctrl+A/C/V 全选复制粘贴
- **多选 / 框选 / 批量操作**：Shift 加选、拖框选、批量移动 / 删除 / 改类型
- **右键 / 长按菜单**：删除、复制、粘贴、四类型互转
- **时间轴**：音乐波形直接画在时间轴上 + 变速段可视化 + 吸附 7 档（关/1/1-2/1-4/1-8/1-16/三连音）+ 方向键逐格精修 + 滚轮以光标为锚缩放
- 视图：缩放 0.25~8×、平移、**跟随判定线**

### RPEN 本体接入

- **整个 Re:PhiEdit Next（rpe-next 0.13）原样搬进游戏**：499 个 ES 模块、21MB 资源，源码零改动
- 打开即自动载入曲库谱面 + 音乐 + 曲绘，改完 **Ctrl+S 原地写回**谱面目录（旧文件自动备份 .bak）
- 技术上解决了 WebView 自定义协议下 ES module 被同源拦截的问题：内置 127.0.0.1 本地静态服务（Rust 起服，端口固定防丢项目库）

### 制谱周边

- **曲线编辑器**：30 种缓动函数可视化预览
- **谱面 diff / 合并**：递归 patch，两个版本的谱面一键对比合并
- **谱面管理面板**（ChartPanel.html）：批量管理本机谱面
- 时间轴编辑器（timing_editor）与谱面工具箱（chart_toolbox）独立页面

## 4. 渲染与分享：出片一条龙

- **离线渲染 mp4**（record.rs）：1080p60、4×MSAA 抗锯齿、CRF18 高画质；PBO 环形异步回读
  - 三平台各有编码后端：Windows 外部 FFmpeg、**Android MediaCodec（JNI）**、**iOS AVAssetWriter**
- **曲库一键渲染**：渲染按钮 → 后台队列 → 窗口实时进度条，渲染完不卡界面
- **导演模式运镜**：push / pull / orbit / sway / drift 五种镜头语言的后处理相机（CamPass），渲染出片自带运镜
- **分享码**：`PHIRA1.` 前缀压缩编码，**本地生成二维码**（不联网），扫码即导谱
- **prpr-monitor**：独立监控窗口，实时观察引擎状态

## 6. 界面：从零重做的一整套 WebView UI

官方 0.8.2 是纯原生界面；本版把整个「游戏外壳」重做成 WebView + 78 个桥函数：

**19 个页面**：开始页（index）、**曲库（library）**、设置（Setting）、工具（tools）、收藏夹（tripsUide）、制谱器（ChartEditor）、谱面管理（ChartPanel）、成长树（Growth）、回放（Replays）、MOD 管理（Mod）、资源包（ResPack）、PhigrOS、BP 主持入口（bpHost）等

### 曲库（重做的重头）

- 搜索、五分类（本地 / 上架 / 特殊 / 未上架 / 热门）、批量删谱、右键管理
- **双排版切换**：**正常排版 ⇄「第九章·穹顶孤舟」章节地图**——地图式选曲界面；**地图上的歌曲节点直接由本机曲库生成**（曲绘自动抓取、缩略图铺满地图），点开详情一键开局；剧情/线索/档案节点保留原作世界观
- 完整移动端重排布局（手机横屏专用，桌面零改动）

### 视觉

- **磨砂玻璃视觉方案**（glass / theme）：深色底 + 玻璃面板 + 高级质感的整套 UI 组件（prpr/src/ui 全新组件层）
- 界面字体统一（原生 UI 与网页同字体），支持设置里导入自定义字体

### 移动端 / 触控

- 全页面 safe-area 安全区、触控目标 ≥40px、300ms 点击延迟消除
- 制谱器触控防误拖（6px 阈值）、单指 / 双指手势全套
- RPEN 与第九章地图各自的移动端样式层（不改源码）

### 多语言

- 网页层 i18n（l10n_web.json），跟随游戏语言

## 9. 工程与发行

- **三平台真实可编**：Windows（exe 全功能）/ Android（arm64 APK，本机一条脚本 15 分钟出包）/ iOS（完整 Xcode 工程 + 视频编码 native 侧，出无签名 IPA 自签）
- **视频引擎打通**：FFmpeg 静态库三平台解码链（prpr-avc），官方 9 段开场 / 解锁视频完整支持
- **与官方版共存**：包名 `org.flos.phira.modded`，不覆盖官方客户端
- **APK 瘦身**：161.5MB → **54.6MB（-66%）**——内置视频改为「谱包 → 数据目录 → 内置」三级回落，字体去重，功能零损失
- **本地静态服务**：Rust 起 127.0.0.1 服务托管 ES module 页面（RPEN / 第九章地图通用，含路径穿越防护、固定端口保数据）
- **GPL-3.0-only 开源**，保留上游版权；CI 自动出包（Android APK + iOS IPA）
