# Phira 0.8.2 修改版 —— 项目介绍

> 基于 [TeamFlos/phira](https://github.com/TeamFlos/phira) 0.8.2 的改版，GPL-3.0-only 开源。
> 面向"想把准度练上去、想看清自己每一局的表现、想和朋友自己开一局联机、还想让成绩进官方排行榜"的玩家。

## 一句话

**一个把"练准度"和"看表现"做到位的 Phira 改版，外加一个 Windows 联机开服器，成绩照常上传官方服务器。**

---

## 打歌：把该看见的都摆出来

**判定**
- 判定窗口可**分别**设置（Perfect / Good / Bad），另有 late 侧补偿（默认 0，即完全对称）
- 判定文字：PERFECT / GOOD / BAD / MISS，四种出现动画、字号可调，配色带同色外发光
- 漏键标记：Bad / Miss 的位置在判定线上留一个淡出的叉，哪里漏了一目了然

**观感**
- 音符拖影（每个音符最多 255 个残影）、判定线残影、判定线发光
- 音乐可视化：判定线上按频谱跳动的条（自写 FFT，无额外依赖）
- 触点标记：圆形 / 方框等样式、颜色、透明度均可调
- 全屏判定、黄色键 / 红色键保护（防止误触断连击）
- **第 9 章噪域（社区叫红区）**：按官方谱面 `blockAreaList` 还原——区内触摸被拦截
  （压住的音符自然 Miss）、入区时音乐压成低通、以及官方贴图 / 触摸悬停 / 溶解边界的完整表现

**实时数据（九宫格可定位）**
- ACC、判定计数、最大连击、时间误差、预估 RKS、进度、FPS
- Early / Late 实时提示，直观看出自己偏快还是偏慢
- 暂停界面可直接调判定偏移与音乐 / 音效音量，不用退出重进

**便利**
- 摇一摇重新开始；打歌界面字体可在「原版 Phigros 字体」和「Phi-Recorder 使用的字体」之间切换

## 成绩：能看、能存、能传官方

- **成绩历史页**：趋势图、判定分布、PB 对比、JSON 导入导出
- **每日挑战**：按日期生成，带约束条件
- **官方成绩上传**：打完官方谱面直接上传到 Phira 官方服务器，进云端排行榜、参与 RKS / 经验结算
  - 默认关闭，开启前需阅读并同意免责协议（会上传什么、不会上传什么都写清了）
  - 使用自动播放、变速等影响公平的选项时不会上传；设置里有一键切换到可上传配置
  - 想只存本地就关掉开关，成绩不会离开设备

## 联机：自己开服，不用买服务器

`launcher/` 是一个 Windows 单文件程序（Tauri + Rust，约 10 MB），把"开一局联机"这件事压到三步：

- 自动挑出**稳定的公网 IPv6**（避开隐私扩展产生的临时地址）
- **免费动态域名**（dynv6）自动更新：你的前缀变了，别人填的域名不用改
- **Windows 防火墙规则**一键配置 + **四项自检**（IPv6 / 防火墙 / 监听 / 域名），哪里不通直接告诉你
- 内嵌联机服务端，界面实时显示房间状态与事件流
- 会显示可供分享的地址和二维码

跨网络的三条路（公网 IPv6 直连 / Tailscale / 主机补公网 IPv4）连同排错问答，都写在
[`launcher/联机使用教程.txt`](../launcher/联机使用教程.txt) 里。

**玩家侧不需要任何修改**：用本改版（或官方客户端）在设置里填上开服器显示的地址即可。

## 技术上的几个点

- **判定与评分对齐官方**：用来校验收发字段的那两条样本，分数都能用官方评分公式精确复现
- **与官方版共存**：包名是 `org.flos.phira.modded`，不会覆盖官方客户端
- **开源与合规**：GPL-3.0-only，保留上游版权声明；官方美术 / 音频资源不随仓库分发，
  由 CI 在构建时从官方安装包提取（见 [`开源步骤.md`](../开源步骤.md)）
- **CI 出包**：`.github/workflows/android.yml` 出 APK，`ios.yml` 出无签名 IPA（用 AltStore / Sideloadly 自签）
- **界面字体**：HarmonyOS Sans（可随应用分发），也可在设置里导入自己喜欢的字体

## 适合谁

- 想认真练准度、需要实时误差与判定分布反馈的人
- 喜欢复盘自己每一局表现的人
- 想和朋友自己开一局联机、又不打算为此买服务器的人
- 想看自己成绩进官方排行榜、但想要一个更好用的客户端的人

## 使用前请知悉

- 成绩上传会把本局成绩提交到**官方服务器**并公开可见；使用影响公平性的选项不会上传，
  但若绕开限制，后果（成绩被判定异常、被删除、账号被限制等）由使用者承担
- iOS 包是**无签名**的，需要自签安装
- 本项目是社区改版，与 Phira 官方无隶属关系；请支持官方与谱师
